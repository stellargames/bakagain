What it is

BaK-Again runs the story, world, rules and art of Betrayal at Krondor in a new engine built with Unity, on Windows, Linux and Android. It reads everything from your own copy of the original game: it ships none of the game's content.

The rules come from a careful reverse-engineering of the original, checked side by side against the 1993 game running in an emulator. Where a modern machine allows better, BaK-Again looks better, but combat, magic, travel and the story should behave the way you remember.

It is free, open source (MIT), and a fan project: it is not affiliated with or endorsed by the rights holders of Betrayal at Krondor.

Status: alpha

All nine chapters can be played from the first scene to the ending. Plenty is still rough, and some fights may turn out harder than in the original. That is what the alpha is for: play it, and tell us where it goes wrong.

Download

The current build is v0.1.4-alpha.

Windows (64-bit, 75 MB) Linux (64-bit, 75 MB) Android (69 MB)

  • Windows: unzip anywhere and run BaK-Again.exe.
  • Linux: unzip and run BaK-Again.x86_64.
  • Android: install the .apk (allow installs from your browser or file manager when asked).

Checksums, release notes and earlier builds are on the releases page.

System requirements

  • Windows: Windows 10 or 11, 64-bit, with a DirectX 11 graphics card.
  • Linux: a 64-bit distribution (tested on Ubuntu) with Vulkan or OpenGL 3.2 graphics.
  • Android: Android 8.0 or newer on a 64-bit (ARM64) device.
  • About 200 MB of free space, plus your copy of the original game.

Getting started

  1. Get Betrayal at Krondor. It is sold on GOG; an old CD copy works too. The 1.02 CD version is the one BaK-Again is tested against.
  2. Install it, or copy its folder somewhere. BaK-Again needs the folder that holds KRONDOR.001. If you are not sure where that is, search your installation for that file name.
  3. Start BaK-Again. The first time, it asks for that folder. Point it there and play.

Modding

Anything BaK-Again loads from the original game can be replaced without touching the original files: put your version in an Overrides folder next to the game files. How it works is documented in the source repository.

FAQ

Do I really need the original game?
Yes. BaK-Again is an engine, like ScummVM or OpenMW: the world, the text, the pictures and the music all come from your copy.
Can I load my old saves?
BaK-Again reads and writes the original's save format, so saves move both ways.
Windows says "Windows protected your PC". Is it safe?
BaK-Again is not code-signed, so Windows SmartScreen warns about any new download from an unknown publisher. Click More info, then Run anyway. If you would rather check first, compare the file with SHA256SUMS on the releases page, or build it yourself from the source.
Android blocks the install, or Play Protect warns about it.
Android warns about every app that does not come from the Play Store. Allow your browser or file manager to install unknown apps when asked; if Play Protect shows a warning, choose More details, then Install anyway.
Is it finished?
Not yet. It is an alpha: the whole game can be played through, but expect bugs.
I found a bug. Where do I report it?
On the forum, in Bug Reports. Please include the version and log path shown at the bottom of the Preferences screen.
Can I help?
Please. Playing and reporting is the biggest help right now. Code, documentation and mods are welcome on GitHub.

BaK-Again stands on the work of others: the Spice86 emulator, which made checking against the original possible, and the fan projects that kept the game alive before us, among them xBaK and BaKGL. Thank you.
