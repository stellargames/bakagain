# Contributing

Thank you for your interest in improving this port of Betrayal at Krondor!

## Project direction

This project has an established design and roadmap. The maintainer
is responsible for its overall direction and has final say over
which features and changes are included.

## Before starting work

For substantial changes, please open an issue to discuss the
problem and proposed approach before beginning implementation.

Please wait for agreement on the approach before submitting a
large pull request. This helps avoid duplicated effort and work
that may not fit the project.

## Contributions we welcome

- Reproducible bug fixes
- Compatibility improvements
- Tests and useful test cases
- Documentation improvements
- Focused performance or reliability improvements

New features and major design changes should be discussed first.

## Pull requests

Every contribution is subject to review and may be declined if
it does not fit the project's goals, design, quality standards,
or maintenance capacity.

Pull requests should be focused, explain their purpose, and include
appropriate testing evidence.

Opening a pull request does not guarantee acceptance. The
maintainer may close proposals that are out of scope.
